# 固定参考的计算兼容修正

来源为 miao-plugin `7f6f1c84c89102bc6b1c58c8e1b06c61f4642161`，版权见 `LICENSES/miao-plugin-MIT.txt`。

- 真珠的 `calc.js` 查询“目标治疗·百分比生命 / 目标治疗·固定值”，同快照 `data.json` 实际命名为“治疗·百分比生命 / 治疗·固定值”，导致两条治疗结果为 NaN。打包器仅替换这两个名称，各两处，数量不符即停止。技能描述与原算式均采用防御力缩放，保留该计算方式；数据字段中的“生命”不被用来推断缩放属性。
- 刻律德菈的军功攻击力提升查询不存在的“攻击力提高上限”，导致文字结果为 `NaN点`；同快照技能描述与数值表明确使用“攻击力”比例。打包器只修正这一处字段名，保留取整与缩放规则；非有限的文字计算结果也会被拒绝。
- 海瑟音的调试 `logger.info` 留在固定公式中；执行环境提供不输出内容的日志函数，避免战斗数值被写进宿主日志。
- 旅行者的元素资料均使用内部 ID 7；按实际角色 ID 与元素选择独立规则，避免不同元素的文件互相覆盖。
- 星铁强化角色依照 `MysPanelHSRApi` 的固定角色名单和技能编号前缀选择强化规则，并重映射行迹编号。官方查询、权限和界面角色选择保留原始角色 ID；伤害和评分均使用对应形态的参考数据。
- 星铁标记 `isSame` 的常量表使用第一项，动态等级表保持原索引；不存在且实际参与计算的值仍会导致明确失败，不补零。

这些是固定参考兼容修正，不修改 `external/参考项目`。角色情境与默认增益沿用参考并在结果中显示，不声明为玩家的实际战斗状态。
