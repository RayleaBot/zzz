# 验收与交付计划

本计划承接主仓库 RayleaBot 的游戏插件返工计划中尚未完成的 R7 阶段（验收与交付）；R0 至 R6c 已完成，其内容随主仓库文档删除，不再保留。记录日期：2026-10-02。

## 验收口径

- 用户可见功能以 Windows 实例上的 Core、真实账号和真实聊天消息验收，并与上游同一命令的输出对照；合成数据测试只用于回归，不能替代验收。
- 对照的上游仓库与固定提交见 [DATA_SOURCES.md](../DATA_SOURCES.md)，下文括号内写上游页面或模块名。
- 与上游有意不同的行为见文末一节，对照时不算缺陷。
- 验收结束时提交本仓库，不推送。

## 待验收事项

- 前缀与帮助：专属前缀 `%`、`％`、`绝区零`、`绝区`、`zzz`、`ZZZ`，不响应通用前缀，管理员可在插件配置修改；`%帮助`（ZZZ-Plugin help），宿主菜单的“绝区零帮助”转交该命令。
- 体力与信息：`%体力` 及其同义词（ZZZ-Plugin note）、`%卡片` 与 `%角色`（card）、`%练度统计`（proficiency，读取代理人详情）、`%邦布`（Yunzai 原神插件的邦布列表图，不超过 8 个时窄版）、`%月报`（monthly，年月写法）、月报统计（monthly/collect）。
- 面板：`%更新面板`（绑定账号时逐角色读取官方数据，转入后台事件，角色间隔 `panel_role_interval`；未绑定或写“展柜”时读取 Enka 并经 Enka2Mys 转为官方格式；同一 UID 在刷新间隔内只更新一次）、`%更新展柜面板`、`%面板列表`（panel/list）、`%<角色>面板`（panel/card：Score 评分脚本、权重与副词条强化次数、官方条目；立绘、音擎与套装图按需从 ZZZeroUID 镜像下载）、`%伤害`（panel/damage，词条增减与序号选技能；本插件补充的 33 个音擎效果只留给管理页试算）、`%上传<角色>面板图`、`%查看<角色>面板图[页码]`、`%删除<角色>面板图1,2`（超级管理员，合并转发列表，每张不超过 5 MB）、`%原图`（看过面板后十分钟内，只取面板图与伤害图中的立绘）。
- 挑战与排名：式舆防卫战、危局强袭战、拟境湮灭战、临界推演、拟真鏖战试炼（ZZZ-Plugin 对应页面）、枯萎苗圃（先查概要，尼尼微受过伤害时再读刀耕火焚）、迷失之地、迷宫诡域、迷宫记录、区域收集（hollowZero、hollowZeroS2、zenkov、explorationDetail）、零号空洞固定提示；群排名按 ZZZ-Plugin rank 九页（式舆、危局、拟境、临界与爬塔四个赛季）：群内查询即登记、显示与隐藏某玩法或全部排名、`%爬塔排名` 列出可查赛季、按玩法清空、剔除已退群成员、临界推演无人上榜的回复；`%排行 <角色>`；挑战提醒：开启与关闭、个人与全局阈值和时间（接受“每日20时30分”“每周一20时”与中文指标名，含 S 评级层数）、`%查询挑战状态`、`%挑战提醒状态`、个人提醒重置；成对提醒合为一个任务，每次只发一条私聊。
- 抽卡：私聊发送调频记录链接读取全部频段（ZZZ-Plugin gachalog，群聊不接收）、`%抽卡链接`、`%获取抽卡链接`（私聊，经账号插件取得本人国服角色的链接）、`%刷新抽卡链接` 与 `%更新抽卡记录`（以账号读取）、`%抽卡分析`（gachalog；独家频段计入 UP 判定，常驻与邦布频段除外）、`%卡池` 的五种写法（poolHistory；在线读取 GachaClock 的 history.json，缓存六小时，读不到时沿用上次结果或随插件快照）、`%导入记录` 与 `%导出记录`（UIGF v4，群聊写“强制”；含 UIGF 未收录频段时导出完整档案格式并可再次导入）、抽卡帮助。
- 设备：`%绑定设备`（两分钟内发送设备信息，群聊建议私聊并在成功后提示撤回）、`%绑定设备帮助`（合并转发，下载链接取插件配置 `device_download_url`）、`%解绑设备`、`%设置默认设备`（超级管理员，安卓设备信息须含 deviceName、deviceBoard、deviceModel、androidVersion、deviceFingerprint、deviceProduct）；出现 10041 时的提示。
- 资料：`%<角色>技能[等级]` 与影画、意象、命座写法（static.nanoka.cc，manifest 取最新版本，版本与资料缓存十二小时；越界等级与多余内容按上游不回复，未知角色按上游回复“暂无X角色数据”“未找到X的数据”）、角色培养材料图（Atlas）、别名增删与查看、`%日历`（官方“活动日历”公告的图片）。
- 公告与推送：公告、资讯、活动、米游社搜索（Yunzai mysNews）、群公告推送、`%推送公告`。
- 素材：`%素材更新`、`%素材状态`（ZZZ-Plugin、Atlas 绝区零图鉴；随包素材约 32 MB）、`%下载全部资源`（超级管理员，转入后台事件，回复各类总数与成败）、`%删除全部资源`（只删除按需下载的图片缓存）、刷新间隔与攻略显示个数设置。
- 无账号与 @ 他人：`%绑定uid<UID>`、`%uid`、`%uid<序号>`、`%删除uid<序号>`（通用头像与绝区零横幅）；命令 @ 他人时读取对方当前 UID，只读取已保存的记录、面板与展柜。
- 写法：上游规则不接受紧跟命令的 UID；技能等级写在空格后可以读到；月报的年月写法。

## 受限事项

- 海外账号与国际服：未验收（国际服不需要设备绑定）。
- 设备验证 10041：需要用户按 ZZZ-Plugin 的设备绑定流程或在官方应用处理后，用真实账号验收角色列表与面板读取。
- GachaClock 卡池历史：上游数据止于 2026-05-05，读不到时沿用上次结果或随插件快照。
- Linux 与 macOS：只有交叉构建，未实机运行。

## 与上游的有意差异

- 使用专属前缀并关闭通用前缀；`%帮助` 由插件出图。
- 已有上游排名后，不提供提交挑战、挑战排行、退出挑战与清空挑战，保留 `%排行 <角色>` 与挑战提醒；按玩法清空只接受上游的三种玩法。
- 不提供上游没有的版本抽卡、公开信息、互动、戳一戳、搜索、帖子、推演概况、保存月报、照片、图鉴图与聊天中的体力推送（管理页保留）；去掉上游从未生效的刷新抽卡间隔与没有对应的刷新角色间隔；去掉“月报 YYYYMM”的空格写法与挑战命令上游没有的“本期”。
- `%更新抽卡记录` 按上游在原聊天回复结果，不带全量与增量参数；抽卡记录按所指定、当前使用或被 @ 用户的 UID 读取档案，不按 CK 隐藏。
- 群聊不接收抽卡链接（与上游默认设置相同）；`%获取抽卡链接` 只在私聊回复；设备绑定在群聊可用但建议私聊。
- 渲染精度与插件更新类命令属于宿主职责，不复刻。
- CK 与 SToken 只经扫码登录或管理页加密导入；聊天中出现凭据时提示撤回。
