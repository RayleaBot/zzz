# 绝区零插件

独立的 RayleaBot Go/Vue 插件，要求包含通用插件服务能力的 Core。游戏增强直接在本插件内实现；账号使用独立的米游社账号插件。

## 当前能力

- 通过 `accounts` v1 共用一次米游社登录，读取已授权角色并选择默认 UID；游戏插件不持有 CK。
- 基础信息、实时便笺、角色列表与基础角色详情；当前主要挑战的摘要和已适配队伍记录。
- 按固定参考版本提供 163 条离线角色、装备等资料，支持查询和自定义别名。
- 从 Enka 读取公开展柜，遵守响应 TTL 缓存；展示公开角色与已适配属性。
- UIGF 文件导入、去重、档案统计与分批导出。大整数记录 ID 保留为字符串，原始本地时间不转换；未完成的导入不改变已有档案。
- 独立的游戏查询、资料图鉴、抽卡档案、体力提醒与面板历史管理页，聊天结果优先渲染图片，渲染不可用时回退文本。

命令以 `info.json` 的实际声明为准，使用本插件的专属前缀，不响应宿主的通用前缀：默认 `%`、`％`、`绝区零`、`绝区`、`zzz`、`ZZZ`，管理员可在插件配置的 `command_prefixes` 中修改。下文以 `%` 为例，`%体力` 与 `绝区零体力` 等价。公开资料、公开 UID 展柜和管理页中的历史抽卡档案可在未安装账号插件时使用。聊天抽卡查询只读取当前主体已验证角色的档案，公开 UID 不授予查看私有记录的权限。

- 管理页可复用已绑定账号同步官方抽卡记录，支持增量/全量、取消和失败继续；读完所有卡池后才保存，避免半途失败改变原档案。
- 重映/回响频段独立统计；含 UIGF 尚未支持卡池的档案完整导出为可回导的 JSON，不丢弃记录。

## 官方查询扩展

危局强袭战、拟境湮灭战、拟真鏖战试炼、临界推演、零号空洞、迷失之地、迷宫诡域、区域探索及菲林月报。

可在游戏查询页选择对应业务，或使用 `info.json` 中声明的命令。月份省略时读取官方默认月份；原神可填 1–12，星铁和绝区零可填 YYYYMM。挑战期数 1 为本期、2 为上期；模拟宇宙另有 3 的接口默认范围。

实际账号已验证可用只读端点及相关期次参数，未参与玩法的丰富历史记录仍需继续验收。受限功能保留在完整目标中。

## 详细面板与评分

角色面板展示官方属性、装备词条、技能及命座/星魂/影画；管理页可展开效果说明。星铁可输入角色名称/ID，留空显示轻量角色概览。

使用 `%评分 角色 [UID]`，管理页也可计算。评分读取当前授权账号的实时详情，不接收伪造面板；权重按上游规则随角色当前属性、影画与配装自动选择。缺少必要数据的装备不评分。评分不是完整伤害计算。

## 记录与体力提醒

- 抽卡档案的“查看统计”提供按池、稀有度、日期和物品筛选的分页明细，以及月份、物品分布和完整间隔均值；未知稀有度不输出确定保底，档案变化后重新从第一页读取。
- “面板历史”页面主动读取并保存官方角色面板，每个角色最多 20 份，可查看、比较属性/配装/技能、导出或移除。保存时间与资料版本一并展示；撤销账号授权后不能继续访问历史。
- “体力提醒”页面选择账号、阈值和期限，确认后开启每十分钟检查。只私聊账号所属用户，持续高于阈值只通知一次，低于阈值后重新待发。聊天使用 `%体力提醒 80 [UID]` 开启 30 天委托，`%关闭提醒 [UID]` 停止。
- 提醒状态跨重启保存，验证失败退避一天，账号移除/授权撤销/到期后暂停。发送结果不明确时不自动重复发送；进程恰在发送前崩溃可能漏一次通知。现有账号默认不启用提醒。

## 群内设置与主动参评

“群内设置”页面可编辑本游戏的群启停、图片/文本回复和群别名，并确认清空本地排行。群设置优先于全局，保存时校验版本；不同协议、机器人和群分别保存。聊天 `%群设置` 由群管理员、群主或超级管理员使用。

群成员可用 `%提交排行 角色 [UID]` 主动公开自己的 UID、昵称和装备评分，用 `%排行 角色` 查看本群参评记录，用 `%退出排行 [角色]` 移除自己的记录。群停用或没有 CK 时仍可退出。此功能不是全服排名，不自动刷新已提交面板。

## 游戏签到与公共资料

“游戏签到”支持状态、当月奖励、单次领取和显式开启每日任务。聊天使用 `%签到 [UID]`、`%签到状态 [UID]`、`%自动签到 开启/关闭 [UID]`。自动任务默认北京时间 08:00、30 天、不主动通知；管理页可改时间、期限与私聊结果选项。验证码或首次绑定在官方应用处理；未确认的上游写入不反复重试。

“游戏查询”中的公共查询池入口或 `%公开信息 UID [区服]` 只查询目标公开基础资料，使用本人主动加入公共池且仍授权本游戏的账号，不会借用私人账号。账号所有者在账号插件本人私聊中设置用途与预算；没有可用账号/额度时明确提示。

## 抽卡后台与每日同步

“抽卡档案”中的“后台与每日同步”可为已授权国服角色开启单次或每日任务。支持增量/全量、1–90 天授权、北京时间执行时刻和可选完成通知；关闭页面后继续，默认不发送通知。即时同步入口仍需保持页面打开。

聊天使用 `%同步抽卡 [增量/全量] [UID]` 创建七天有效的单次任务，`%自动同步 开启/关闭 [UID]` 创建或停止每日 08:00 的增量任务（30 天）。`%同步进度 [UID]` 查看进度，`%停止同步 [UID]` 停止任务；进度和停止在 CK 不可用、群停用时仍可使用。

每分钟最多读取三页，全部池成功后合并。重启会重新读取未完成的一轮；已导入或删除的档案不会被旧暂存覆盖。删除档案会先暂停对应后台任务。设备验证、授权撤销或记录冲突会暂停；解决后可明确重新运行，过期委托需移除后重建。停止保留已有档案。

## 开发与打包

工具链沿用 RayleaBot：Go 1.26.6、Node 26.7.0、pnpm 11.22.0。`game-plugin-kit` 是编译期源码依赖，不需安装为运行时插件。

```powershell
node scripts/prepare-ui.mjs
corepack pnpm --dir ui install --frozen-lockfile
go test ./...
corepack pnpm --dir ui test
corepack pnpm --dir ui run build
$env:RAYLEA_PLUGIN_BUILD_USE_WORKSPACE='1'
go run github.com/RayleaBot/RayleaBot/sdk/go/cmd/raylea-plugin build-go --backend ./cmd/plugin-zzz --target windows-x64 --include DATA_SOURCES.md=DATA_SOURCES.md --include .rayleabot/source.zip=ui/source.zip
```

打包前在相邻 `game-plugin-kit` 中运行 `python scripts/source-bundles.py`，以提供对应源码。源码包保留相邻 SDK、业务库与 `go.work`，可按上述结构构建。独立从远端检出时，当前未发布的 SDK v0.7.1 与业务库 v0.1.0 仍需相邻源码。

另支持 `linux-x64` 和 `macos-arm64`。数据文件位于宿主提供的本插件数据目录内；抽卡记录属于非凭据业务数据，使用原子文件替换保存。

## 查询、历史与群榜

查询结果下可展开完整分组和记录，切换期次/月份后重新查询。月报查询页可保存指定月份、依次保存官方可用月份、累计已保存收入及删除月份。明细和本地历史每次读取重新检查角色授权。

群内“游戏提交挑战 玩法 [本期/上期] [UID]”主动公开本人成绩；“游戏挑战排行 玩法 [期次] [指标] [页码]”分区查看，“游戏退出挑战 [玩法]”删除本人参评。群管理页提供玩法筛选、重新排序和按期清理。提醒页可开启每日/每周挑战目标检查，未达目标才私聊；“游戏关闭挑战提醒 [UID]”可取消，不影响体力提醒。

卡池资料页支持角色/装备历史、版本和日期筛选及出现次数；抽卡明细页可按版本统计本地档案。资料来自固定快照，推定日期及未覆盖记录明确标记。

提醒页的“每日月报收集”可为所选角色开启有期限的每日保存，通知默认关闭。停止任务不删除已保存月报。


## 社区、兑换码与公开资料

“社区与云游戏”页提供账号级米游币和明确的社区操作，一次/每日任务可分别选择浏览、点赞和分享。云原神/云绝区零另需在账号插件配置加密云授权，钱包查询可能领取当日时长，操作前须确认。所有定时任务默认关闭。

“兑换码与资产”页匿名读取官方前瞻代码；国服在游戏内兑换，已授权海外角色提供固定官方兑换接口。原神/星铁可分批保存官方当前可读的资产变化记录，按月与来源统计；这些数值不代表实际付款金额。

“公告与活动”页支持官方新闻分页、米游社搜索、文章全文分段及原图链接、国服活动日期。缺失活动时间保留原文，不把公告展示期限当作活动期限。聊天“绝区零订阅 公告/资讯/活动/到期 [天数]”开启有期限的推送，首次检查不发送旧新闻，群操作需要管理员；“绝区零退订 [类型]”关闭。

“攻略与工具”页可选择并保存默认攻略来源、浏览合集和官方原图；原神另提供地图服务链接、尘歌壶摹本材料和固定 Atlas 原魔计算。生日沿用材料与卡池页的日期查询。未明确许可的外部攻略和图鉴素材不预装。

## 本地图库与角色互动

“图库与互动”页支持图片/目录批量导入、分类/角色关联、修改信息、预览、原图下载与删除。使用者须有对应素材许可。图片不做二次转换；上限为每张4 MiB、2400万像素，全库2000项、512 MiB。WebP按[公开容器规范](https://developers.google.com/speed/webp/docs/riff_container)读取尺寸，浏览器验证能否显示。

发送“绝区零照片 角色名”“绝区零图鉴图 分类 [关键词]”读取图库，“绝区零原图”重取当前聊天内十分钟内由本人查询的图片。“绝区零互动 伙伴 设置/添加/移除/列表/随机/照片/卡片 [角色名]”管理自己的娱乐角色列表，亦支持老婆/老公/女友/男友/女儿/儿子称呼；不推断缺失的性别或年龄资料。

戳一戳默认关闭，以“绝区零戳一戳 开启/关闭”自行选择。各游戏插件互不协商，同时在多个游戏开启的用户会收到各自的回复；同一主体十秒冷却。对应服务只返回启用标记，与账号凭据无关。


## 帮助与冲突设置

“帮助与版本”页及帮助/版本命令使用安装包同版本的命令声明。全局和群别名可选择自定义优先、内置优先或拒绝冲突；群策略可继承全局。

国服与海外授权由账号插件区分，游戏侧仍使用同一服务；海外星铁支持官方同步，国服完整逐抽限制保留。星铁另提供 Mihomo 公开展柜来源与基于已保存开拓力记录的在线窗口估算；估算不等于官方在线时长。
